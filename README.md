# Ali Trader v1.46 — مؤشر دخول ذهب XAUUSD

مؤشر MetaTrader 5 هجين يجمع أقوى المدارس الحديثة في محرك نقاط واحد، مع تنبيهات كاملة ولوحة معلومات عربية.

## المزايا
- **SMC**: كسر الهيكل BOS/CHoCH + أوردرك بلوكس + فجوات FVG
- **السيولة**: سحب السيولة Liquidity Sweep (اصطياد الستوبات)
- **الاتجاه**: فلتر EMA 50/200 من فريم أعلى تلقائي (H1/H4)
- **الجلسات**: لندن ونيويورك فقط + فلتر ATR
- **تعزيزات v1.43**:
  - فلتر الدولار DXY العكسي (+1)
  - دايفرجنس RSI المؤكد (+2)
  - فلتر ADX لجودة الترند (+1 / −1)
  - سحب النطاق الآسيوي مع افتتاح لندن (+2)
- **جديد v1.46 — إنهاء حيرة الفريمات نهائياً**:
  - **وضع صارم** `InpMTFStrict` (افتراضي مفعّل): لا إشارة شراء إلا إذا كان 15د وساعة صاعدين معاً، ولا بيع إلا إذا كانا هابطين معاً — عند التعارض تتوقف الإشارات كلها لحد ما الفريمات تتفق
  - **فلتر التوافق يشمل علي ماستر** كمان: الإشارات المستقلة بقت خاضعة لنفس بوابة الاتجاه الموحدة `MTFAllow` — مفيش محرك يخالف الفريمات الأعلى
  - **صف "المسموح الآن"** في اللوحة: سطر واحد يجيب فوراً: شراء فقط / بيع فقط / لا إشارات - انتظر التوافق
  - لو عايز إشارات أكثر: أطفئ الوضع الصارم وسيب `InpMTFAlignBlock` للحظر فقط
- **جديد v1.45 — فلتر توافق الفريمات**:
  - حل مشكلة تعارض الفريمات (دقيقة هابط / 5د هابط / ربع ساعة صاعد / ساعة صاعد)
  - إشارة الشراء تُحظر إذا كان الفريمان الأعلى (15د + ساعة) هابطين، والعكس للبيع `InpMTFAlignBlock`
  - +2 درجة عند توافق الفريمين الأعلى مع الاتجاه (السقف حتى 18)
  - صف لوحة جديد يعرض اتجاه دقيقة / 5د / 15د / ساعة لحظياً مع حكم: توافق صاعد / توافق هابط / تعارض
  - حساب الاتجاه من شمعة مغلقة على الفريم الأعلى — بدون إعادة رسم
- **تحديثات v1.44**:
  - حماية الانعكاس: لا إشارة معاكسة إلا بعد انتظار 10 دقائق (قابل للتعديل `InpRevWaitMin`)
  - الدخول من المنطقة الذهبية فقط (فيبو 0.5-0.618) `InpGoldenEntry`
  - هدف ثالث TP3 للمحركين (المحرك الرئيسي 3R + علي ماستر 3×ATR)
- **تنبيهات**: منبثق + صوت + إشعار جوال
- **إشارات غير معاد رسمها** (Non-Repaint): كل شمعة تُقيَّم عند إغلاقها فقط
- استراتيجية علي ماستر v6 مدمجة (خطوط دخول/أهداف/ستوب + مناطق سيولة 4H)

## التركيب
1. حمّل ملف `Ali_Trader_v1.46.mq5`
2. في المنصة: File → Open Data Folder → مجلد `MQL5\Indicators`
3. افتح MetaEditor (F4) وافتح الملف واضغط **Compile (F7)**
4. من نافذة Navigator ابحث عن **Ali Trader** واسحبه على شارت **XAUUSD**
