## الأهم — البوت لا يحتاج المؤشر
نسخة البوت **v2.00** تحتوي محرك الإشارات كاملاً داخل الملف نفسه:
- محرك SMC: كسر الهيكل + أوردرك بلوكس + FVG + سحب سيولة
- استراتيجية علي ماستر v6: اختراق 3 شموع + أهداف ATR
- كل الفلاتر: اتجاه EMA + جلسات + حجم + ATR + أخبار حمراء + DXY + دايفرجنس RSI + ADX + سحب آسيا + توافق الفريمات (الوضع الصارم)
- **ملف واحد → Compile مرة واحدة → يعمل.** لا يوجد أي `iCustom` ولا أي شرط كومبايل مسبق لمؤشر.

### تركيب البوت (3 خطوات فقط)
1. انسخ `Ali_Trader_EA.mq5` إلى مجلد `MQL5\Experts`
2. افتحه في MetaEditor واضغط **Compile (F7)** — لن توجد أخطاء
3. اسحب **Ali Trader EA** على شارت **XAUUSD** وفعّل زر **Algo Trading** الأخضر

بعد الإرفاق بثوانٍ ستظهر لوحة الحالة أسفل يسار الشارت:
`Ali Trader EA v2.00 — المحرك: شغال ✓ (مستقل - بلا مؤشر خارجي)`
