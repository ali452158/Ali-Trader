# Ali Trader v1.47 — مؤشر دخول ذهب XAUUSD + بوت التداول التلقائي

مؤشر MetaTrader 5 هجين يجمع أقوى المدارس الحديثة في محرك نقاط واحد، مع تنبيهات كاملة ولوحة معلومات عربية — و**بوت EA** يفتح الصفقات تلقائياً من إشارات المؤشر.

## الملفات
| الملف | الوصف |
|-------|-------|
| `Ali_Trader_v1.47.mq5` | المؤشر (يوضع في `MQL5\Indicators`) |
| `Ali_Trader_EA.mq5` | بوت التداول التلقائي (يوضع في `MQL5\Experts`) |

## المزايا
- **SMC**: كسر الهيكل BOS/CHoCH + أوردرك بلوكس + فجوات FVG
- **السيولة**: سحب السيولة Liquidity Sweep (اصطياد الستوبات)
- **الاتجاه**: فلتر EMA 50/200 من فريم أعلى تلقائي (H1/H4)
- **الجلسات**: لندن ونيويورك فقط + فلتر ATR
- **تعزيزات v1.43**:
  - فلتر الدولار DXY العكسي (+1)
  - دايفرجنس RSI المؤكد (+2)
  - فلتر ADX لجودة الترند (+1 / −1)
  - سحب النطاق الآسيوي مع افتتاح لندن (+2)
- **v1.45 — فلتر توافق الفريمات**: لا إشارة عكس اتجاه 15د وساعة + صف لوحة اتجاهات دقيقة/5د/15د/ساعة
- **v1.46 — وضع صارم**: لا إشارات إلا باتفاق الفريمين كاملاً + الفلتر يشمل علي ماستر + صف "المسموح الآن"
- **جديد v1.47 — جسر البوت**:
  - 4 بافرات جديدة تُقرأ عبر `iCustom`: 8=ستوب الإشارة، 9=TP1، 10=TP2، 11=TP3
  - البافرات تُملأ تلقائياً مع كل إشارة مؤكدة (للمحركين) — التاريخ كله متاح للباك تست
  - مخفية عن نافذة البيانات — مظهر المؤشر لم يتغير
- **تنبيهات**: منبثق + صوت + إشعار جوال
- **إشارات غير معاد رسمها** (Non-Repaint): كل شمعة تُقيَّم عند إغلاقها فقط
- استراتيجية علي ماستر v6 مدمجة (خطوط دخول/أهداف/ستوب + مناطق سيولة 4H)

## Ali Trader EA — البوت التلقائي
يقرأ إشارات المؤشر عبر `iCustom` ويدير الصفقات بالكامل:

| الميزة | التفاصيل |
|--------|----------|
| مصدر الإشارة | علي ماستر / المحرك الرئيسي / الاثنين معاً |
| حجم الصفقة | لوت ثابت أو نسبة مخاطرة % من الرصيد (تحسب من مسافة الستوب) |
| الحماية | فلتر سبريد + حد أقصى صفقات + صفقة واحدة لكل شمعة + حد صفقات يومي + رقم سحري |
| الستوب والهدف | من بافرات المؤشر أو ثابتة بالنقاط + حدود أقل/أكبر مسافة |
| إدارة الصفقة | نقل للتعادل بعد R محدد + تريلينج ستوب + إغلاق جزئي |
| الإغلاق المعاكس | يقفل الصفقة عند جاءت إشارة عكسية ويفتح الاتجاه الجديد |
| الإشعارات | موبايل عند الفتح والإغلاق (يوضح سبب الإغلاق: ستوب/هدف) |
| لوحة الحالة | على الشارت: عدد الصفقات، السبريد، آخر إشارة، حالة التداول الآلي |

### تركيب البوت
1. كومبايل `Ali_Trader_v1.47.mq5` في `MQL5\Indicators` أولاً (إلزامي)
2. كومبايل `Ali_Trader_EA.mq5` في `MQL5\Experts`
3. اسحب البوت على شارت **XAUUSD بنفس فريم المؤشر**
4. فعّل زر **Algo Trading** الأخضر من الشريط العلوي
5. ملاحظة: البوت يستدعي المؤشر بإعداداته الافتراضية — لتغيير إعدادات المؤشر عدّل القيم الافتراضية داخل ملف المؤشر نفسه ثم أعد Compile

> تحذير: ابدأ على حساب تجريبي (Demo) واختبر في Strategy Tester قبل أي حساب حقيقي، ولا تجعل المخاطرة تتجاوز 1-2% لكل صفقة.

## تركيب المؤشر
1. حمّل ملف `Ali_Trader_v1.47.mq5`
2. في المنصة: File → Open Data Folder → مجلد `MQL5\Indicators`
3. افتح MetaEditor (F4) وافتح الملف واضغط **Compile (F7)**
4. من نافذة Navigator ابحث عن **Ali Trader** واسحبه على شارت **XAUUSD**
